隐私说明

适用于 Wenruo OmniFocus Mac Bridge · 更新日期：2026 年 10 月 13 日

访问哪些数据

Google 权限仅为 drive.file，用于由应用创建或专门获准访问的通信文件，不请求全盘权限。运行代码固定通信表及获批测试项目范围。

命令含请求 ID、会话绑定、操作类型、授权引用、有效期、目标稳定 ID 与具体字段。预览和回执含获批合成任务的稳定 ID、名称、所属项目、状态、必要日期、字段指纹、执行前后快照和不存在核验。具体人类批准记录留在 Mac 本地，绑定单个命令与预览摘要，远端请求文字不能自行授予权限。

范围仅原合成样本及获具体批准后由本机成功创建的少量临时任务；不读取无关项目、任务笔记或其他应用凭据。

数据用途与传递

通信数据仅用于获授权的查询、预览及具体批准的新增、更新、完成、重开、单任务删除，核验结果、防止重复执行和恢复回执交付。Google 托管通信表；Mac 保存执行与交付账本及本地批准记录；用户授权 AA 读取通信结果。执行账本不是第二套任务数据库。

Wenruo OS 恢复和知识写回遵循独立规则。桥接不售卖数据，不用于广告或训练通用模型；Google 与 AI 平台自身的数据处理规则由对应平台政策决定。

通过 Google API 取得信息的使用和传递遵守 Google API Services User Data Policy，包括 Limited Use 要求。

凭据与保存

刷新凭据保存在 Mac 钥匙串；客户端配置留在用户指定的本机位置，不进入通信表、公开网页或验收包。当前测试保留有限历史供验收和恢复，没有自动到期清除。历史清理与保留期调整单独处理。

撤销与清理

用户可在 Google 账号第三方连接设置撤销访问，阻止后续凭据刷新和通信。撤销不自动删除 OmniFocus 数据、已有通信记录或本机历史；清理由所有者按恢复需要单独处理。

公开说明站点

本站无登录、数据表单、分析脚本或追踪器。GitHub Pages 可能按其政策保存访客 IP 等访问记录。

说明更新与联系

新操作或范围变更前更新说明与相关授权。公开说明问题可通过 公开说明问题反馈 联系，请勿提供私有资料。
